
# Gestor de Tareas 2027
Proyecto de introducción al curso 2027
## Todo-List v0.1

Gestion de la lista de tareas desde la consola

## Funcionalidad
1. Añadir una nueva tarea
2. Ver tareas pendientes
3. Marcar una tarea como completada
4. Borrar una tarea
5. Filtrar tareas por prioridad
6. Guardar lista de tareas
7. Salir

Para ejecutar el comando escribe el numero correspondiente y pulse `Enter`

Cada vez que se ejecuta un comando, este se imprime en pantalla y seguido de esto se imprime el menú para seleccionar el siguiente comando.
## Implementacion
Se necesita usar la version 24 de Java.
